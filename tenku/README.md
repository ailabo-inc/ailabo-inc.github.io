# 天空（仮）— ドラクエ5 DS の素材で作る個人用ゲーム

個人利用のファンゲーム。**ROMや抽出素材はこのリポジトリに一切入れない**（公開サイトのため）。
ゲームは実行時に、プレイヤーの端末にあるROMから素材を読み込む（OpenRCT2等と同じ方式）。

## ゲーム企画：『天空の系譜』
DQ5の核である「親子三代」「モンスター仲間」を、何度も遊べる形に作り直す。

- **世代ローグライトRPG**：1周＝1世代。パパス → 主人公 → 子供へと世代を重ね、
  前の世代で得た仲間モンスター・装備・記憶（スキル）が次の世代に引き継がれる
- **DQ5の素材をフル活用**：キャラ・モンスターのドット絵、マップのタイル、BGM・効果音をROMから読み込む
- **DS超えの表現**：WebGL（Three.js）で「HD-2D風」— ドット絵キャラ＋立体的な地形、
  光と影、被写界深度、天候。DSの解像度に縛られない60fps
- **iPhoneで快適に**：縦持ち片手操作、PWAでホーム画面から起動

## 構成
| 層 | 内容 | 状態 |
|---|---|---|
| ROM読み込み | .nds / .7z / .zip を端末内で展開、IndexedDBに保存 | ✅ |
| 形式解析 | NitroFS, LZ10/11, NARC, NCLR, NCGR, NSCR | ✅ |
| 天空ラボ | ROMの中身を見る解析ツール（`index.html`） | ✅ |
| 形式解析 | NCER/NANR（スプライト・アニメ）、NSBMD/NSBTX（3D）、SDAT（音） | 次 |
| DQ5独自形式 | ラボで調査して判明したら追加 | 次 |
| ゲーム本体 | Three.js で HD-2D エンジン → 戦闘 → 世代システム | 次 |

## 開発
```
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト（疑似ROMを組み立てて検証）
npm run typecheck
npm run guard      # ROM・抽出データがgitに入っていないか検査
npm run build
```
